# Development Roadmap

## V0.1 Brain
Ollama, Qwen3 1.7B, terminal chat, streaming.

## V0.2 Agent
Structured tool calls, router, validator, execution loop.

## V0.3 Memory
SQLite, explicit memory, retrieval.

## V0.4 Personality
Modes, humor controls, concise response renderer.

## V0.5 Local tools
Calculator, time, system info, file search/read.

## V0.6 Web
Search adapter and source-aware responses.

## V0.7 Security
Permissions, confirmation, cancellation, path restrictions.

## V0.8 Performance
Latency instrumentation, prompt trimming, caching, fewer calls.

## V0.9 Voice
STT, TTS, interruption.

## V1.0 Desktop
GUI and optional controlled desktop skills.

Only move forward when the previous milestone is stable.
