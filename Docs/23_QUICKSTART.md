# Quickstart

## Verify Ollama
```bash
ollama list
ollama run qwen3:1.7b
```

## Create Python environment
```bash
python -m venv .venv
```

Activate it and install the minimal dependencies.

## Run
```bash
python -m app.main
```

## First tests
