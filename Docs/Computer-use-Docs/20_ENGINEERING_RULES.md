# Engineering Rules

1. Minimal dependencies.
2. Local-first.
3. Deterministic tools before model reasoning.
4. Semantic UI targeting before coordinates.
5. Accessibility/UI tree before screenshots.
6. Screenshots before vision models.
7. One action at a time for uncertain tasks.
8. Verify every important state transition.
9. Never blindly repeat failed actions.
10. Keep prompts short.
11. Keep model calls low.
12. Keep action count low.
13. Never claim success without verification.
14. Separate personality from execution.
15. Ask before meaningful external/destructive effects.
16. Provide a global emergency stop.
17. Log execution metadata, not secrets.
18. Do not expose arbitrary shell/Python execution.
19. Keep the core runtime understandable.
20. Optimize successful completion, not just raw latency.
