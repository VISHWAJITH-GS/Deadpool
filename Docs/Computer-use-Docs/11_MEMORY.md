# Lightweight Memory

Use SQLite.

## Store

```text
preferences
application aliases
project locations
user-defined commands
explicit memories
```

Example:

```text
"my coding project" → C:\Projects\TCE-Connect
"browser" → Microsoft Edge
```

## Do not store automatically

- passwords
- authentication tokens
- private credentials
- sensitive information

## Retrieval

Only retrieve memories relevant to the current task.

Maximum default retrieval: 3–5 records.

Memory must never override explicit instructions from the current user.
