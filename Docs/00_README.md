# Deadpool Agent — Lightweight Technical Documentation

A minimal, fast, precise local desktop AI agent built around Qwen3 1.7B through Ollama.

The personality uses broad traits such as wit, sarcasm, confidence and self-awareness, with original wording rather than imitation of a specific copyrighted character or actor.

## Design priorities
1. Fast response
2. Low resource usage
3. Precise tool execution
4. Minimal dependencies
5. Local-first operation
6. Deterministic actions
7. Clear permissions
8. Modular skills
9. Easy debugging
10. Small codebase

## MVP
- Qwen3 1.7B via Ollama
- terminal conversation
- short-term context
- explicit long-term memory
- personality modes
- structured tool calls
- calculator
- time/date
- system information
- file search/read
- web-search adapter
- permission checks
- cancellation
- logging

## Non-goals for v1
Android control, unrestricted shell execution, autonomous destructive actions, continuous screen monitoring, complex multi-agent orchestration, heavy vector databases and large frameworks.
