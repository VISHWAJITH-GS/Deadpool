# Definition of Done

- [ ] App and website specifications work.
- [ ] Installed apps can be discovered.
- [ ] Apps can be launched/focused.
- [ ] Websites can be opened directly.
- [ ] Aliases work.
- [ ] Multi-step tasks work.
- [ ] Qwen3 1.7B handles complex/ambiguous planning.
- [ ] Mouse works.
- [ ] Keyboard works.
- [ ] Active window can be observed.
- [ ] UI elements can be read.
- [ ] Screenshot fallback works.
- [ ] Important actions are verified.
- [ ] Safe recovery works.
- [ ] Risky operations require confirmation.
- [ ] Emergency stop works.
- [ ] Webpage instructions are treated as untrusted.
- [ ] No unrestricted command execution exists.
- [ ] Simple commands use deterministic fast paths.
- [ ] Metrics are available.

Primary acceptance task:
"Open Chrome app, go to LeetCode website, find Two Sum."

The agent must resolve, execute, observe, verify, recover if needed, and stop.
