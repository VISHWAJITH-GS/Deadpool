# Safety and Confirmation

SAFE — automatic:
- open/focus apps
- open known websites
- read UI
- screenshots
- scroll
- ordinary navigation

CONFIRM:
- send messages
- submit forms
- publish content
- modify important files
- install software
- purchase/order
- external communication

DANGEROUS:
- delete files
- uninstall software
- change security settings
- system configuration
- arbitrary commands

Provide a global emergency-stop hotkey. It must cancel pending actions and prevent new actions until resumed.

Do not expose unrestricted shell/Python execution to the LLM in v1.
